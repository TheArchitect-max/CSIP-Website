# CSIP Website

Public GitHub Pages showcase for **Continuum State Integrity Platform**.

Continuum is a private proprietary research software project. This repository contains only the public presentation layer: static HTML/CSS, original project visuals, and high-level product information suitable for public disclosure.

## Public site

Expected GitHub Pages URL:

`https://thearchitect-max.github.io/CSIP-Website/`

## Scope

This website describes what Continuum is intended to do, why the project exists, its high-level capabilities, design principles, and current public project status.

It intentionally does **not** contain:

- proprietary Continuum source code;
- implementation algorithms or reconstructable internal architecture;
- private configuration, schemas, runbooks, prompts, datasets, or test data;
- credentials, tokens, secrets, private endpoints, or environment files;
- authentication, payment, checkout, database, or server-side application functionality;
- claims of scientific validation, production certification, or guarantees not supported by the project.

## Visual assets

The visual identity and SVG assets in `assets/` were created specifically for this public project website and do not reproduce third-party artwork or stock imagery. See `ASSET_PROVENANCE.md`.

## Technology

The site is deliberately static and dependency-free:

- semantic HTML;
- responsive CSS;
- local SVG assets;
- no external JavaScript;
- no trackers;
- no advertising;
- no external font or image requests.

## Relationship to the core project

The Continuum core remains private/proprietary. Publication of this website repository does not grant a license to the underlying Continuum software or disclose its implementation.
